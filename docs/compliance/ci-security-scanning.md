## Turning each check into a blocking gate

One line each. Do this only after the findings below are fixed or accepted.

- **npm audit (runtime):** delete `continue-on-error: true` from the "Audit runtime dependencies" step in `security.yml`.
- **npm audit (full):** delete `continue-on-error: true` from the "Full audit report" step and change the command to `npm audit --audit-level=high --json > npm-audit.json` (it fails on any finding at all otherwise).
- **SBOM:** already fails if generation fails (`if-no-files-found: error`); nothing to flip.
- **gitleaks:** delete `continue-on-error: true` from the "Scan git history" step.
- **CodeQL:** delete `continue-on-error: true` from the analyze step in `codeql.yml`, then in repository Settings → Code security → code scanning set the PR check to fail on "High or higher" security alerts.
- **cdk-nag:** already a blocking gate through `npm test` in `ci.yml` (`infra/test/nag.test.ts`). To also block on this job, delete `continue-on-error: true` from the "cdk synth" step (cdk-nag errors make synth exit non-zero).
- **Make any of them required:** add the job name to the branch protection rule's required status checks for `main`.

## Open points

- **CodeQL upload on a private repository** needs GitHub code scanning (Advanced Security) enabled. Until then the analyze step's upload fails; `continue-on-error` keeps the run green. Decide whether the repository is public or code scanning is enabled.
- **Who triages** the weekly scheduled runs and how fast (SI-2 needs remediation time frames by severity). Proposed: critical and high in runtime dependencies within 30 days, others at the next dependency update. Needs the project owner.
- The SSP row "SBOM, vulnerability scanning in CI" (`system-security-plan.md`) now says "Built (warn-only)" (updated 2026-11-11).
- Not every job is strictly warn-only: the SBOM job fails if generation fails, and the npm-audit summary step fails if `npm audit --json` returns no JSON (for example a registry outage). Both are tool failures, not findings.
