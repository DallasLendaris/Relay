# cdk-nag NIST 800-53 rev 5 exceptions register

> **Draft, pending review by the agency ISO.** Nothing is deployed. These are engineering decisions recorded so a reviewer can accept, reject or schedule each one.

`infra/bin/relay.ts` applies the cdk-nag `NIST80053R5Checks` pack (cdk-nag 2.38.2) to every stack. An unsuppressed finding is an error, so `cdk synth` fails, and `infra/test/nag.test.ts` synthesizes dev and prod and fails on any unsuppressed NIST error or warning. `-c nag=off` skips the pack for quick local synths only.

Every exception below is a `NagSuppressions.addResourceSuppressions` call in `infra/lib/compliance.ts`, scoped to the named resources (there is no stack-wide suppression; a test checks that). The code resolves each resource by its construct path and throws if it is gone, so this register cannot silently drift from the infrastructure. A new resource that trips a rule fails synth until it is fixed or added here.

Controls are the ones cdk-nag maps to the rule (from its report); the list is abridged to the families that matter for each decision.
